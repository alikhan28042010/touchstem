# TouchSTEM ⠿

**Любая картинка с частями — схема, график, план школы, клетка, панель микроволновки — за пару минут становится листом, который незрячий ученик читает пальцами. А телефон над листом делает его говорящим.**

Учитель фотографирует электрическую схему из учебника (или вводит формулу графика) и получает:

- **тактильный лист**: STL для 3D-печати и SVG 1:1 для рельефной бумаги — рельефные линии,
  упрощённые символы, номера шрифтом Брайля (русский и казахский), срезанный угол для ориентации;
- **лист обозначений** шрифтом Брайля;
- **урок**: маршрут пальца по схеме («веди палец вниз, затем вправо — дойдёшь до номера 4: амперметр»),
  расчёт токов и напряжений, вопросы для самопроверки с ответами;
- **аудиогид** для телефона ученика: QR-код на листе учителя открывает пошаговую озвучку;
- **проверку читаемости** по правилам тактильной графики (балл 0–100 и что исправить);
- **лист учителя (PDF)** и оценку печати: граммы пластика, цена в тенге, время;
- **живой лист** — пластина отвечает на касание (см. ниже).

## Живой лист: пластик, который говорит и симулирует цепь

Телефон над листом видит четыре метки на бумажной подложке и цветную наклейку на ногте ученика.
Палец задерживается на элементе — звучит название; поднять и коснуться снова — живые значения из решателя
(«напряжение 2,63 вольт, ток 188 миллиампер»); коснуться ключа третий раз — цепь пересчитывается, и телефон говорит,
что изменилось («Ключ 2 разомкнут. Лампа 3 погасла. Амперметр 4 теперь показывает 0 ампер»). Для графиков —
звук, высота которого следует за функцией, и голос в нулях и экстремумах.

Чем это отличается от существующих систем с камерой (CamIO, TAURIS) и устройств вроде T3 ($750):
там каждую точку размечает человек и озвучка статична. TouchSTEM сам создал лист, поэтому знает координаты
каждого элемента (разметка не нужна), а звук идёт из физической модели цепи — лист можно «переключать» касанием.
Всё работает в браузере телефона, видео не покидает устройство.

Проверено end-to-end: синтетическое видео наклонённой камеры → настоящий `touch.html` в Chromium → фразы
(`E2E=1 pytest -k fake_camera`). Ошибка положения пальца в тесте — меньше 0,3 мм.

Работает приложение: https://touchstem.streamlit.app

## Карта, план, рисунок: не только физика

Третий режим принимает всё, что состоит из частей: план этажа или эвакуации, карту, строение клетки или сердца,
солнечную систему, панель стиральной машины или лифта. Gemini находит части (полигоны в координатах 0–1000),
TouchSTEM рисует рельефные контуры, проходы — точечной текстурой, двери — разрывами в стенах, ставит номера
Брайля внутри каждой части и сам вычисляет соседей и вложенность («Вакуоль находится внутри: цитоплазма»).

- **Накладка 1:1.** Если указать реальную ширину панели прибора, лист печатается в натуральную величину и
  ложится поверх кнопок: незрячий человек сам пользуется микроволновкой, а живой лист объясняет каждую кнопку.
- **Игра «Найди».** Телефон загадывает часть («Найдите: библиотека») и подсказывает голосом «правее», «ниже»,
  пока палец не дойдёт; на месте — звуковой сигнал. Так ученик заранее учит дорогу по школе или запоминает
  строение органа. Работает и для схем.
- Примеры: `examples/school_floor.json`, `plant_cell.json`, `microwave_panel.json` (русский и казахский).

## Живой голос

Все фразы урока, аудиогида и живого листа озвучивает нейросетевой голос Piper: русский (Irina) и казахский
(ISSAI). Числа и единицы превращаются в слова с правильным согласованием («две целых пять десятых вольта»,
«екі бүтін оннан бес вольт»). Фразы синтезируются в фоне на сервере в `static/tts/<sha1>.mp3`; браузер
находит файл по тому же хешу и, пока файла нет, читает фразу голосом телефона.

## Что внутри

| Модуль | Что делает |
|---|---|
| `ai.py` | Gemini Vision читает фото: схему → граф (узлы и элементы), график → формулу и оси. AI ничего не рисует |
| `model.py` | проверка и нормализация схемы: склейка узлов, прямые углы, номера элементов |
| `render.py` | рельеф по правилам тактильной графики, экспорт STL (watertight, manifold3d), SVG, PNG |
| `braille.py` | Брайль по таблицам liblouis (`ru-litbrl`, `kk`), числа, единицы |
| `solver.py` | расчёт цепи методом узловых потенциалов (MNA): токи, напряжения, короткое замыкание |
| `lesson.py` | маршрут пальца по графу схемы, объяснение, вопросы (ru / kk) |
| `graphs.py` | графики функций: безопасный разбор формулы, оси, сетка-текстура, нули и экстремумы |
| `quality.py` | проверка читаемости: ≥3 мм между линиями, отступ Брайля, плотность, размер |
| `share.py`, `guide.py` | данные схемы в QR-ссылке (без базы данных) и аудиогид на Web Speech API |
| `teacher.py` | лист учителя A4 (PDF) |
| `touch.py`, `static/touch.js` | живой лист: горячие точки, таблица состояний цепи, подложка с ArUco-метками, камера + наклейка, гомография |

Новые модули: `regions.py` (карта/план/рисунок → лист, соседи, урок), `tts.py` (нейроголос, очередь
синтеза), `ai.py: parse_regions_image`.

## Запуск

```
python -m venv .venv && .venv\Scripts\activate        # Windows
pip install -r requirements.txt
streamlit run app.py
pytest -q                                              # 37 тестов (+1 браузерный: E2E=1)
```

Secrets (Streamlit Cloud → Settings → Secrets):
```
GEMINI_API_KEY = "..."                      # распознавание фото
APP_URL = "https://touchstem.streamlit.app" # адрес для QR-кодов
```

## Ограничения

- Схемы: постоянный ток; диоды и светодиоды не рассчитываются (только рисуются).
- Подписи без заглавных букв и латиницы — номера элементов и лист обозначений, как принято в тактильной графике.
- Размеры точек и линий — типовые значения тактильной графики; подстройте после тестов с учениками.
- Казахский текст урока и Брайль нужно проверить с тифлопедагогом.

Шрифты: Unbounded и IBM Plex Sans (SIL OFL 1.1). Таблицы Брайля: liblouis (LGPL-2.1+). Метки: js-aruco2 (MIT).
