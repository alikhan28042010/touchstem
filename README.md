# TouchSTEM ⠿

Учитель фотографирует электрическую схему из учебника — приложение делает тактильную
версию с подписями шрифтом Брайля (русский / қазақша):

- **STL** — для 3D-печати (рельефные линии + точки Брайля на пластине);
- **SVG 1:1** — для рельефной (swell) бумаги или брайлевского принтера;
- **обозначения** — отдельный лист: номер элемента → название и значение.

## Как это работает

1. **AI читает схему** (Gemini Vision) → JSON: узлы на сетке и элементы между ними.
2. **Учитель проверяет** таблицу элементов и при необходимости исправляет тип или значение.
3. **Наш рендерер рисует** схему по правилам тактильной графики: прямые углы, упрощённые
   символы, точки в узлах, номера шрифтом Брайля с отступом от линий. AI ничего не рисует сам,
   поэтому лишних форм на рельефе не бывает.

Шрифт Брайля взят из таблиц [liblouis](https://github.com/liblouis/liblouis) (`ru-litbrl.ctb`, `kk.utb`,
LGPL-2.1+), см. `touchstem/braille_tables.json` и `tools/extract_braille_tables.py`.

## Запуск бесплатно (Streamlit Community Cloud)

1. Получи ключ: https://aistudio.google.com → **Get API key** (бесплатный лимит).
2. Создай репозиторий на GitHub и загрузи туда эту папку (без `.venv` и `out`).
3. Зайди на https://share.streamlit.io → **Create app** → выбери репозиторий, файл `app.py`.
4. В **Advanced settings → Secrets** вставь:
   ```
   GEMINI_API_KEY = "твой_ключ"
   ```
5. **Deploy** — через пару минут будет ссылка вида `https://touchstem.streamlit.app`.

## Локально

```
python -m venv .venv && .venv\Scripts\activate      # Windows
pip install -r requirements.txt
streamlit run app.py
```
Тесты: `pip install pytest && pytest -q`.

## Ограничения (честно)

- Пока только электрические схемы. Следующие типы: графики функций, геометрия.
- Подписи без заглавных букв и без латиницы (латиница в русском/казахском Брайле требует
  контекстных правил) — номера элементов + лист обозначений, как принято в тактильной графике.
- Размеры точек и линий — типовые значения; подстрой после тестов с учениками (боковая панель).
- Казахские названия элементов и итоговый Брайль нужно проверить с тифлопедагогом.
